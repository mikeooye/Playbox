# Playbox

使用 Kotlin 与 Jetpack Compose 编写的亲子游戏小工具集合。

## 包含的工具

- **幸运骰子**：原生 Compose 绘制骰面，无图片资源依赖；3D 翻滚、回弹与彩带动画，带触感反馈并记录最近 6 次结果
- **兔子陷阱棋**：抽取行动卡（转萝卜 / 走一步 / 走两步 / 走三步）搭配胡萝卜骰子的桌面小游戏
- **四则运算**：可配置结果范围（例如 1~20）、运算符与卡片数量的练习卡组
  - 点「开始」后先唤醒语音识别，就绪才亮出第一题；整轮录音不中断，答完最后一题自动停止录音并弹出记录
  - 设置与记录面板从底部弹出，可拖动展开到全屏，右上角有 ✕ 关闭
  - 离线语音听写：孩子直接说出答案即可判定，不需要联网、也不依赖系统语音服务；识别中文数字（"十五"）与阿拉伯数字（15）
  - 只说数字：识别器以数字词表为语法，听到的不是数字就返回 `[unk]` 并忽略，不会把闲聊判成错误答案
  - 说出的答案实时显示在卡片的等号后面；答对后卡片变绿停留 0.5 秒，答错两次变红同样停留 0.5 秒，随后卡片在 0.15 秒内上移并淡出，露出下一张
  - 答错卡片变橙、再错变红（不显示正确答案）；两次答错后自动进入下一题，点一下卡片也可立刻跳过
  - 范围指**答案**：答案落在范围内，参与计算的数不会超过最大值（1~20 不会出现 18+17，也不会出现大于 20 的因数）
  - 设置保存在本机，下次打开继续沿用；记录里答错和慢于平均用时的题目会高亮，并显示本轮总用时
- **拼音跟读**：卡片显示音节（如 bā）与例字，孩子读出来自动判定
  - 复用同一套离线识别：每轮把本轮所有音节的汉字作为识别词表，读错成别的卡片或读成无关内容都会被判错
  - **只判声母韵母，声调不参与判定** —— 实测小模型分不清 妈/麻/马/骂，强行判声调会频繁冤枉孩子
  - 答对变绿停留 0.5 秒，答错两次变红后自动进入下一题；答完自动弹出练习记录
  - 声调只作展示；相近韵母（如 爸/大）存在约一成互相误接受，属模型能力边界
- 首页可同时开启两个工具，分屏并排使用

## 运行

使用 Android Studio 打开项目，等待 Gradle Sync 完成后运行 `app` 模块。项目要求 JDK 17。

首次开启语音听写时会请求麦克风权限，并把内置的语音模型解压到应用目录（约 65MB，只需一次）。
卡片内的字号按卡片大小等比缩放，平板上面会更大。

### 离线语音模型

识别使用 [Vosk](https://alphacephei.com/vosk/) 与 `vosk-model-small-cn-0.22`（均为 Apache-2.0）。
模型约 43MB，不进版本库；构建时 `prepareVoskModel` 任务会自动下载到
`app/src/main/assets/vosk-model-cn.zip`，也可以手动放入该文件后离线构建。
因为只识别数字，识别器以数字词表（"零/一/…/一百"）加上 `[unk]` 作为语法启动，
既不会解码出无关句子，也能明确表示"刚才那句不是数字"。

### 测试

- `./gradlew :app:testDebugUnitTest`：数值范围生成、中文数字解析、答题记录的单元测试
- `./gradlew :app:connectedDebugAndroidTest`：在真机上用合成语音验证识别链路
  （数字：12 个必须识别正确、4 句非数字必须被过滤；拼音：4 个音节必须落到对应卡片。
  音频由 `tools/generate-speech-samples.sh` 生成，需要 macOS）

## 下载安装

在 [Releases](https://github.com/mikeooye/Playbox/releases) 页面下载最新的 `Playbox-<版本>.apk` 直接安装即可，无需 Google Play。支持 Android 7.0（API 24）及以上。
