# Playbox

A collection of parent-child mini-game tools built with Kotlin and Jetpack Compose. It currently ships its first tool: Lucky Dice.

## Features

- Native Compose dice faces, no image assets required
- 3D roll, bounce and confetti animations
- Haptic feedback with the last 6 results
- Android 7.0 (API 24) and above

## Run

Open the project in Android Studio, wait for Gradle Sync to finish, then run the `app` module. JDK 17 is required.
